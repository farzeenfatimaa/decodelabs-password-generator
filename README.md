# 🔐 Password Generator

A command-line Python application that generates secure, random passwords using Python's built-in `secrets` module. The application allows users to specify the desired password length and creates strong passwords using a combination of uppercase letters, lowercase letters, digits, and special characters.

---

## 🚀 Features

- Generate cryptographically secure random passwords
- Customizable password length (1–100 characters)
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Input validation for password length
- Simple and user-friendly command-line interface

---

## 🛠️ Technologies Used

- Python 3
- `secrets` module
- `string` module
